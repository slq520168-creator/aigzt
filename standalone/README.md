# IMAI 独立工作台
正式站：https://aigzt.youxuansi.online
Cloudflare Worker：aigzt-standalone；独立 D1 与 R2，禁止复用 IM、YOUXI 或餐饮数据库。
## 当前架构
- Worker 内嵌 index.html、style.css、client.js，静态资源与 API 同源；使用原有 DB、MEDIA、RATE 及加密密钥绑定。
- 聊天分自动（共享免费线路）、自由（个人免费线路）、个人（本人授权模型）。免费供应商可用性和额度由实际服务决定，不承诺永久无限。
- 普通文生图、识图、语音听写、朗读、连续语音对话保留；原工作执行模式、原生视频、GIF、贴纸、图生图生成已移除。
- 作图支持提示词识别和独立任务；图片字节保存在设备 IndexedDB。服务器仅保留任务状态和可再次读取的上游交付地址，地址过期不能保证恢复；不新增生成图片 R2 长期存储。
- 模型、免费工具各40个收藏，按账户隔离，服务器同步及本机缓存；近期使用独立。
- 新版提交以稳定请求 ID 预留去重记录，已完成请求复用结果；不确定请求不重复执行。历史会话切换按请求版本和账户校验。
## 部署与验收
只更新 standalone 四个运行文件的内嵌构建；保留现有 Worker 绑定和独立数据库。新增表见 migrations/20261128-workbench-stability.sql，Worker 有幂等初始化保护。禁止提交密钥。正式手机端真实登录、生成、录音和网络切换必须单独验证；源码测试不等于端到端通过。
